## 📌 Featured Projects  

### 🤖 AI & Data Science
- 🔹 [**Sensai**](https://github.com/jawedlahrouri/Sensai) — *Modular AI Agent & Custom MCP Engine*  
  Python orchestration architecture connected to local LLMs (Ollama) built without third-party agent frameworks. Features Model Context Protocol (MCP) tool execution, autonomous web search, document RAG, dynamic personas, and SQLite persistence across CLI and Web interfaces.

- 🔹 [**my_torch**](https://github.com/jawedlahrouri/torch) — *Deep Learning Framework From Scratch & Chess Analyzer*  
  Neural network library (Dense & LSTM layers, activation functions, backpropagation) built purely with NumPy. Applied to chessboard state classification using Grid Search hyperparameter tuning and data augmentation.

- 🔹 [**Start Trek**](https://github.com/jawedlahrouri/Start_trek) — *Reinforcement Learning Lunar Lander*  
  Autonomous agent trained in Gymnasium's `LunarLander-v3` environment to safely land a spacecraft through custom reward shaping, 2D physics simulation, and trajectory stabilization.

- 🔹 [**CVRIE**](https://github.com/jawedlahrouri/Cvrie) — *Medical Pneumonia Detection via Computer Vision & ML*  
  End-to-end supervised and unsupervised learning pipeline on chest X-ray imagery. Includes PCA dimensionality reduction, model benchmarking (MLP, Random Forest, KNN), and interpretability heatmaps.

- 🔹 [**Persona**](https://github.com/jawedlahrouri/Persona) — *AI-Powered Automated News & Newsletter Pipeline*  
  Automated intelligence workflow orchestrated with n8n and the Google Gemini API to aggregate, synthesize, and broadcast personalized newsletters via Discord webhooks with PostgreSQL storage and GDPR compliance commands.

- 🔹 [**Tardis**](https://github.com/jawedlahrouri/Tardis) — *Exploratory Data Analysis & Train Delay Prediction*  
  Statistical study and predictive modeling on SNCF railway network data, featuring large-scale data cleaning, feature engineering, interactive visualizations, and regression models.

### ⚙️ Fullstack & Systems Engineering
- 🔹 [**Inter-Net**](https://github.com/jawedlahrouri/Inter-Net) — *Modular Web Dashboard & Service Orchestration*  
  Component-driven TypeScript web application centralizing data streams and interactive widgets with third-party REST API integrations and reactive UI management.

- 🔹 [**Zappy**](https://github.com/jawedlahrouri/Zappy) — *Real-Time Network Server & Autonomous AI Swarm*  
  Distributed system combining a C TCP/IP server, a C++ 3D/2D visualizer, and autonomous AI agents communicating via encrypted radio broadcasts to gather resources and coordinate elevation rituals.

- 🔹 [**Raytracer**](https://github.com/jawedlahrouri/Raytracer) — *Photorealistic 3D Raytracing Engine in C++20*  
  Graphics engine simulating physical light transport (shadows, reflections, transparency), built with a modular C++20 Factory architecture and dynamic shared library (`.so`) plugins.

- 🔹 [**42sh**](https://github.com/jawedlahrouri/42sh) — *Full UNIX Command Interpreter (tcsh)*  
  Robust UNIX shell written in C featuring lexical/syntactic AST parsing, process management (`fork`/`exec`), multi-stage pipes, stream redirections, environment variables, and aliases.
